# Inventaire des sources ALTIORA v1 pour le RAG

> Modèle à compléter avec Samuel et ALTIORA. Aucun contenu, URL officielle ou tarif n’est inventé dans ce document.

## Règles d’utilisation

- Une source ne peut être indexée pour le RAG que si son statut est `validé`.
- Le champ « utilisable pour le RAG » doit rester à `non` tant que la validation métier n’est pas obtenue.
- Les données personnelles inutiles, tarifs non validés et engagements contractuels ne doivent pas être ajoutés.
